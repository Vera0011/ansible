# Proxychains

## Introduction

Proxychains is a package available in Linux distributions (Ubuntu, Kali Linux, etc.). It is used to route traffic through multiple machines to mask your traffic. It belongs to the `Red Team` section.

## Implementation

When installed via this repository's Ansible role, Proxychains is set up as follows:

1. Multiple self-hosted proxies are created using Tor, each running as its own service unit.
2. Before creating new Tor services, any existing custom Tor services set up by this role are removed. A new service is then created, using a shared system unit template and a dedicated configuration per instance.
3. Proxychains is configured to use these Tor instances, using a round-robin method.
4. Once configured, traffic generated through Proxychains is redirected through these Tor services.

## Ansible role usage

```yaml
- hosts: example-host
  become: true
  roles:
    - proxychains
  vars:
    proxychains_clean: false
    proxychains_total_proxies: 10
```

### Properties

- `proxychains_clean` (boolean, optional): Whether the role should run in clean mode, removing all existing proxies instead of creating new ones.
- `proxychains_total_proxies` (int, optional): Number of proxies to set up.

## Command-line usage

Once installed, Proxychains can be run directly on the host:

```bash
proxychains -q <service>
proxychains4 -q <service>
```

Traffic generated by `<service>` will be redirected through the configured Tor instances. Note that `<service>` refers to an application (such as `firefox`) or a command (such as `nmap` or `dirsearch`).
